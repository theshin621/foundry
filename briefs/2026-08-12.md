## 2. RECOMMENDATION — `infra/013-stats-window-floor`

**Not one of the three above, and the brief owes an argument for that.** The build order below is
an INFRA fix to `/_b/stats`. Four reasons, in descending strength:

**(a) It is the fix `BOTTLENECKS.md` entry #1 itself nominates.** Entry #1's status block ends:
*"the queued /_b/stats window fix is the next validation candidate."* That was queued 2026-08-09
and is still unbuilt three days later.

**(b) Reading the code to size it turned up a second, worse defect than the one that was queued.**
`src/worker.js:105` is `while (paths.length * days > HARD_CAP) days--;` with `HARD_CAP = 44`.
Computed, not asserted:

| countable paths | resulting window | |
|---|---|---|
| 4 (today) | 10 days | fine |
| 5 (the moment ship 011 merges) | 8 days | fine |
| 6 | 7 days | **exactly at the edge** |
| 7 | 6 days | **below the trailing-7 the stop-condition is defined on** |
| 45 | **0 days** | `dates` is an empty array; every path returns `{}` |

The queued MEDIUM was "the window shrinks as the fleet grows". The unqueued part is that
**it shrinks silently, and past 44 paths it degrades to a total blackout that is byte-identical to
honest zeros** — `window.from` becomes `undefined` and every path reports no traffic. There is no
error, no flag, and nothing in the committed artifact would tell a future fire it was reading a
blackout rather than a quiet fleet. That is the same failure shape as BOTTLENECKS #1 incident #4
(*artifact present, thing inert, instrument green*), this time in the measurement layer the
30-day review depends on.

**(c) Today it is the only thing that can actually publish.** Entry #1 is `fix-shipped` but
**checker-validated: PENDING**, so MOD-1 keeps SHIP merges on Theshin's one-click go — anything
built from E1/E2/E3 today stages and waits. INFRA merges are autonomous on checker-PASS. A ship
today produces a staged branch; this produces a live fix.

**(d) Its PASS is the gate-opener.** Entry #1 validates on the first checker-PASS under the
oracle-first + browser-truth discipline. That flips ship merges to autonomous — permanently, for
every future build day.

**The argument against, stated because it is real:** three of the last five builds have been
infra (008 beacon, 009 oracle, 010 relay). A factory that keeps tuning itself is a factory that
stops shipping, and PLAYBOOK §9.3 names exactly this drift. The defence is that this is bounded
(one endpoint, one relay script), dated (the 6-path edge is two merges away), and that it is the
instrument the whole 30-day review reads — a review run on a blind instrument is ceremony. **E1
`password-csv-remapper` is carried as tomorrow's pick** and is the strongest consumer candidate
the EVERGREEN lane has produced in a week.

### Build order

1. **The window floor is inviolable.** `/_b/stats` never returns a window shorter than 7 days for
   an all-paths read. When `paths × days` would exceed `HARD_CAP`, the endpoint degrades the
   *path* dimension, never the *day* dimension, and it says so: the response carries
   `truncated: { paths_omitted: [...], reason: "subrequest-cap" }`. A consumer can see a missing
   path; it cannot see a missing day.
2. **`days` can never reach 0.** Clamp after the loop, not only before it. A window of zero days
   must be impossible to express.
3. **The relay stops depending on the all-paths call.** `lib/beacon_stats.py` fans out one request
   per countable path (`?path=X&days=N`, bounded 1×30 = 30 < 44, already supported) and merges.
   Each request is its own Worker invocation with its own subrequest budget, so the committed
   artifact is complete **at any fleet size**. The all-paths call survives as a convenience with a
   declared truncation, not as the loop's source of truth.
4. **Oracle before code** (`oracles/013-stats-window-floor/`): a Node harness that imports the real
   `src/worker.js` fetch handler against a stub KV populated with a known synthetic dataset, and
   drives it at fleet sizes 1 → 60. Predicates: window ≥7 for every all-paths read at every fleet
   size · `dates.length === window.days` and both > 0 · counts returned match the synthetic dataset
   exactly · omitted paths are named in `truncated` · total KV gets per invocation ≤ 44. Not a
   liveness-of-markup claim, so no browser is required; the oracle executes the shipped code path
   rather than reading it, which is the same principle.
5. **PROBE-THE-ORACLE** (mandatory, both clauses): (a) negative control — reintroduce the
   `days--` shrink and confirm the oracle goes RED at 7 paths; (b) an independent attempt to build
   a break the oracle still passes, reported whether or not it succeeds.
6. **Kill-criterion:** infra has no public path. Its criterion is instrumental, not visit-based:
   if `public/beacon-stats.json` is ever committed with a window shorter than 7 days, or with a
   path silently absent rather than declared, the fix has failed and reverts.
