The safety model

  • Default run is a pure scan — it writes only its own report and log files.
  • --apply moves to quarantine (~/MacCleaner/quarantine/) with a manifest — --restore is a full undo. Nothing is deleted until you explicitly purge.
  • Structurally unreachable: Documents, Desktop, Dropbox, Pictures/Music/Movies, code folders, iOS device backups — an allowlist plus a protected-list veto on every single move, and (v1.1.4) moves through symlinked parent directories are refused outright, so a relocated-caches setup can't smuggle protected files past the path checks.
  • Refuses to run as root. Timestamps are the only thing restore/purge accept — path traversal is killed at argument parse.
  • Only trash-emptying and explicit purge are permanent, and both are double-gated.

Make your first run the harmless no-argument scan. Trash and orphan actions on a real Mac deserve a look at the report first.

Why not just AppCleaner?

AppCleaner is great at one thing: dragging an app to find its leftovers. maccleaner does the leftover hunt across your whole machine at once plus the gigabytes AppCleaner never looks at — pip/npm/pnpm/yarn/gradle/cargo/Homebrew/Xcode caches, Docker debris, aged Trash — with a stricter model: quarantine first, delete only when you say so, and a report that never lies about what was measured versus estimated.
