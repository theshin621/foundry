To evaluate this you need to understand…

1. Nothing is uploaded. There is no server and no request: the file is read with FileReader and processed in this tab. Open DevTools → Network and watch it do nothing. That is the entire reason this exists rather than a website you paste a transcript into.

2. Pseudonyms are consistent and reversible only by you. The same person is the same Participant N everywhere in the file, and the same in a second run of the same file, so the conversation still reads. The mapping is a separate download that never touches the sanitised file.

3. Bare first names are redacted too. Replacing “Alice Mokoena” and leaving “thanks Alice” in a message body is the failure that makes redaction theatre. Every component of every name is substituted on word boundaries, including non-ASCII ones.

4. It over-redacts on purpose. If a participant is called Will, the word “will” goes too. For a privacy tool the expensive mistake is the one in the other direction.

5. What it does NOT do: media, images inside a .zip, voice notes, or identification by writing style. It removes identifiers. It does not make a chat unattributable — and anyone who already knows the participants will still recognise them from the content.
